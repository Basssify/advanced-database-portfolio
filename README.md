 1. Project Overview

This repository contains the practical activities and technical documentation developed for MIT 8103 – Advanced Database Systems.

The project focuses on the design, implementation, analysis, optimisation and evaluation of database systems using the VIFSET E-Commerce Management System as the selected case study.

VIFSET is a simulated Nigerian e-commerce business that sells products through an online platform. Its database solution manages customers, products, orders, payments, inventory and delivery records.

 3. Portfolio Activities

This project consists of five practical portfolio activities.

 Portfolio 1: Database Design and Modelling
Database requirements analysis, entity identification, Entity Relationship Diagram (ERD), relational schema, primary and foreign keys, constraints and normalisation.

 Portfolio 2: Query Processing and Optimisation
SQL query development, query execution plans, indexing, query optimisation and performance analysis using MySQL.

 Portfolio 3: Transactions and Concurrency
Implementation and analysis of database transactions, COMMIT, ROLLBACK, isolation levels and concurrency control.

Portfolio 4: NoSQL and Advanced Data Models
Development and implementation of a NoSQL data model using MongoDB Atlas. This includes document-based data storage, queries, update operations and aggregation pipelines.

Portfolio 5: Distributed and Cloud Database Exercise
Exploration of cloud database deployment and distributed database concepts using MongoDB Atlas. The practical work includes logical data partitioning across separate collections and cross-partition queries using `$unionWith`. Concepts such as replication, sharding, consistency and availability are also discussed.
