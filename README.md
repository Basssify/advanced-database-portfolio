 1. Project Overview
This repository contains the practical activities and technical documentation developed for MIT 8103 – Advanced Database Systems.
The project focuses on the design, implementation, analysis, optimisation and management of an advanced database system using VIFSET E-Commerce Management System as the selected case study.

VIFSET is a simulated Nigerian e-commerce business that sells products through an online platform. The system is designed to manage customers, products, orders, payments, inventory and delivery records.

2. Case Study Description
The VIFSET E-Commerce Management System is designed to provide an organised and reliable database solution for managing online retail operations.

Database Users
- Customers
- Administrators
- Inventory managers
- Sales personnel
- Delivery personnel

Major Data to Be Stored:
- Customer information
- Product details and categories
- Customer orders and order items
- Payment transactions
- Inventory and stock records
- Delivery and shipment information

Major Database Operations:
- Customer registration and management
- Product creation and updating
- Order placement and processing
- Payment recording
- Inventory and stock management
- Delivery tracking
- Sales reporting and data retrieval

3. Portfolio Activities

This project consists of five practical portfolio activities:

Portfolio 1: Database Design and Modelling
Database requirements analysis, entity identification, Entity Relationship Diagram (ERD), relational schema, keys, constraints and normalisation.

Portfolio 2: Query Processing and Optimisation
SQL query development, query execution plans, indexing, query optimisation and performance analysis.

Portfolio 3: Transactions and Concurrency
Implementation and analysis of database transactions, COMMIT, ROLLBACK, isolation levels and concurrency control.

Portfolio 4: NoSQL and Advanced Data Models
Development of a NoSQL data model using the selected case study, including implementation examples and evaluation of its suitability.

 Portfolio 5: Distributed and Cloud Database Exercise
Exploration of distributed database concepts, replication, sharding, consistency, availability and cloud database deployment.
